# ☕ Chat Web - CRUD com PHP e MySQL

Aplicação web de chat desenvolvida com PHP, MySQL, HTML, CSS e Bootstrap, com foco em autenticação de usuários, gerenciamento de mensagens e integração com banco de dados relacional.

🚀 Acesse o projeto online

🔗 [https://SEU-LINK.infinityfreeapp.com](https://luizchat.infinityfree.me)

## 🚀 Funcionalidades

* Cadastro de usuários
* Login e autenticação com sessões
* Envio de mensagens em tempo real na aplicação
* Exclusão de mensagens pelo próprio usuário
* Listagem dinâmica de mensagens
* Controle de permissões
* Integração com banco de dados MySQL
* Interface responsiva utilizando Bootstrap

## 🛠️ Tecnologias utilizadas

* PHP
* MySQL
* HTML5
* CSS3
* Bootstrap
* PDO
* Session PHP

## 📚 Conceitos aplicados

* CRUD completo
* Programação orientada a objetos (POO)
* Relacionamento entre tabelas
* Sessões e autenticação
* Segurança básica com prepared statements
* Organização em classes e separação de responsabilidades

## 🎯 Objetivo do projeto

O projeto foi desenvolvido com o objetivo de praticar conceitos fundamentais de desenvolvimento back-end com PHP e banco de dados MySQL, simulando um ambiente de comunicação entre usuários cadastrados.
